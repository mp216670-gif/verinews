## Reporting a Vulnerability

If you discover a security issue in VeriNews, **please do not open a public GitHub issue.**

Instead, report it privately by emailing the maintainers or opening a **GitHub Security Advisory**:

1. Go to the repository's **Security** tab
2. Click **"Report a vulnerability"**
3. Fill in the details and submit

We will respond within **48 hours** and aim to patch critical vulnerabilities within **7 days**.

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional but welcome)

Thank you for helping keep VeriNews safe for everyone.
